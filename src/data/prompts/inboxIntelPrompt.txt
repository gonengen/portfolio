# AI Job Search Intelligence — Master Prompt

Use my Gmail as the primary source of truth for my job search.

Your goal is to build a complete, data-driven analysis of my job search — not just count applications and rejections.

Analyze my current applications, retrieve their job requirements, investigate my previous application history with each company, and identify patterns that may explain which applications progress and which are rejected.

Do not invent missing information.
Clearly distinguish between OBSERVED DATA, CORRELATION, and SPECULATION.

---

# Step 1 — Find Current Applications

Search Gmail for every job application I submitted during the last 30 days.

Include applications submitted through:

- Company career pages
- LinkedIn
- Greenhouse
- Lever
- Workday
- Comeet
- Ashby
- SmartRecruiters
- Recruiter outreach
- Direct email
- Other ATS platforms

Identify duplicate emails belonging to the same application and consolidate them into one record.

---

# Step 2 — Build the Application Database

For every current application, extract:

| Field | Description |
|---|---|
| Company | Company name |
| Job Title | Exact role title |
| Application Date | Submission date |
| Application Method | LinkedIn / Career Site / Recruiter / Referral / Direct Email / ATS |
| Current Status | Waiting / Rejected / Interview / Assessment / Offer / Other |
| Last Activity | Date of most recent recruiting-related interaction |
| Rejection Date | If applicable |
| Days Since Applied | Calculate automatically |
| Days to Rejection | If rejected |
| Days to First Response | If a response was received |

---

# Step 3 — Retrieve the Job Description

For every application, retrieve the original Job Description whenever possible.

First search Gmail for the original posting or application confirmation.

If the full description is not available there, search:

1. The company's official careers website
2. Greenhouse
3. Lever
4. Workday
5. Comeet
6. Ashby
7. Other public job boards or cached/searchable copies

Prefer the exact historical posting associated with my application.

IMPORTANT:
If you find a current posting with the same title but cannot verify that it is the same version I applied to, mark it as:

POSSIBLE MATCH — NOT VERIFIED

If the original Job Description cannot be reliably found, mark it:

UNAVAILABLE

Do not reconstruct or invent the requirements.

# Step 5 — Previous Application History

This step is critical.

For EVERY company in the current application list, search my Gmail history for ANY previous job application or recruiting interaction with that same company during the LAST 12 MONTHS.

Search for:

- Previous application confirmations
- Previous rejection emails
- Recruiter outreach
- Interview invitations
- Assessments
- Scheduling emails
- ATS notifications
- Previous roles at the same company

Do this even if the previous application used a different job title.

For each company, add:

| Field | Description |
|---|---|
| Applied Before | Yes / No |
| Previous Application Date | Most recent previous application |
| Previous Job Title | Previous role |
| Previous Status | Rejected / Interview / Assessment / Withdrawn / Unknown |
| Days Since Previous Application | Difference between previous and current application |
| Same Role | Yes / No |
| Previous Applications Count | Number found during the last 12 months |

Classify each current application as:

- FIRST APPLICATION
- REAPPLIED < 3 MONTHS
- REAPPLIED 3–6 MONTHS
- REAPPLIED 6–12 MONTHS

IMPORTANT:

A previous application does NOT prove that it caused a current rejection.

Do not claim that an ATS automatically rejected me unless there is direct evidence.

Different email addresses, phone numbers, names, LinkedIn profiles, or other identifiers MAY potentially allow recruiting systems to associate candidate records, but do not assume this happened unless evidence is available.

Report the historical relationship first, then test whether a pattern exists.

# Step 6 — Analyze Reapplication Patterns

Compare FIRST APPLICATIONS with REAPPLICATIONS.

Calculate where the available sample allows:

- Rejection rate for FIRST APPLICATIONS
- Rejection rate for all REAPPLICATIONS
- Rejection rate for REAPPLIED < 3 MONTHS
- Rejection rate for REAPPLIED 3–6 MONTHS
- Rejection rate for REAPPLIED 6–12 MONTHS
- Interview rate for first applications
- Interview rate for reapplications
- Assessment rate for first applications
- Assessment rate for reapplications
- Median / average time to rejection for each group

Pay special attention to:

## Fast Rejections

Identify applications rejected:

- Same day
- Within 24 hours
- Within 3 days
- Within 7 days

Check whether unusually fast rejections correlate with:

- Previous applications to that company
- Applying recently to the same company
- Applying to the same role
- Seniority mismatch
- Specialized domain requirements

Do NOT label a rejection "automatic" based only on speed.

# Step 14 — Strategic Diagnosis

Answer the following questions based ONLY on the available data:

1. Is my CV generating interviews / assessments?

2. Are rejection rates unusually concentrated in particular industries?

3. Are reapplications being rejected more frequently than first applications?

4. Are recent reapplications associated with faster rejection?

5. Am I applying to roles above my seniority?

6. Which domains currently show the strongest response?

7. Which application channels perform best?

8. Which requirements appear most frequently across the jobs?

9. Are important skills buried too deep in my CV?

10. Does my positioning appear too broad?

11. Is there evidence that Enterprise, AI, or Consumer positioning performs better?

12. Are there enough observations to draw these conclusions confidently?

# Step 15 — Confidence & Evidence

This section is mandatory.

For every major conclusion, label it as:

### STRONG EVIDENCE
Supported by enough observations and a clear pattern.

### EARLY SIGNAL
A pattern exists, but the sample is still small.

### SPECULATION
Plausible explanation, but not supported by enough evidence.

Never present speculation as fact.

For small sample sizes, explicitly state that the result may change as more applications are collected.

# Final Rule

Treat this as a DATA ANALYSIS task, not motivational career coaching.

Do not try to make the results sound positive or negative.

If the data suggests my strategy is working, say so.

If the data suggests something is failing, say so.

If the sample is too small to know, say that.

The goal is to discover what is actually happening in my job search and improve future decisions based on evidence.
